GOOD QUESTIONS. CLEAR ANSWERS.

了解多一点。
开始，更从容。

关于接入、数据与发布的一些说明。

ModelPulse 现在可以下载了吗？+

目前处于产品规划阶段，尚未发布安装包。官网展示的是交互概念，发布日期、售价与授权方式均未确定。

可以直接监控所有 AI 客户端吗？+

不能假设所有客户端都提供内部用量。计划通过官方 API、事件接口和用户授权的结构化日志逐步接入；每个适配器会明确支持哪些指标。

真实报告和估算如何区分？+

每项数据都会标注来源。API 或客户端报告、Tokenizer 估算与推断数据分别呈现，缺失值标为“不可用”，费用估算也不等同于供应商账单。

会保存我的提示词和 API 密钥吗？+

规划默认只保存用量元数据，不保存提示词或回复。用户配置的 API 密钥将使用 Windows 安全存储；代理由用户主动配置，默认仅监听本机。

悬浮窗能按我的习惯定制吗？+

这是产品的核心设计：自由选择、重复添加组件，分别绑定数据源并调整布局、标题、颜色与阈值。计划支持多套预设和 JSON 布局导入导出。

支持哪些系统和模型平台？+

目标平台是 Windows 10/11 x64，优先适配 Windows 11。计划先完成一个可验证的 API 适配器，再逐步扩展 OpenAI、Anthropic、Gemini 及 OpenAI 兼容服务。
